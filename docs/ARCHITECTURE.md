# 구현 안내

## 관심사의 분리

초기 프로토타입은 eco_engine.py의 순수 계산과 app.py의 시연 화면, parameters.py의 초기 계수를 분리합니다. FoodInput과 EcoLevelResult 데이터 클래스로 입력과 결과 구조를 명시하고 단계별 계산 로그를 반환합니다.

후속 engine 모듈은 입력 검증과 특징 변환에 집중합니다. FoodFeatureVector는 변경 불가능한 모델이며 원본 데이터가 없는 특징은 None으로 유지합니다. 데이터 완전성 점수와 경고가 결과와 함께 제공됩니다.

## 수치의 의미

폐기 경로 확률은 초기 규칙 기반 점수에 softmax를 적용한 모델 출력이며 실측 통계로 학습·보정된 확률이 아닙니다. 환경부하 벡터도 상대 점수로, kg CO2e 등 절대량이 아닙니다. 보상 포인트는 시연 정책이며 실제 금전·정산 체계와 연결하지 않았습니다.

## 검증과 남은 과제

입력 모델은 모르는 필드를 거부하고 원재료 비율 합계, 시간대, 소비기한과 판매 마감 관계를 검증합니다. 특징 변환은 정상 입력, 누락 정보, 판매 마감 경과 및 48시간 이상 남은 경우를 테스트합니다.

실측 계수 보정, 외부 검증, 실제 서비스의 인증·정산·API 배포는 이 공개본의 구현 범위가 아닙니다.

## 공개본의 구성 원칙

관련 비공개 개발 저장소에서 검토한 텍스트 소스만 선별해 새 저장소에 복사하는 스냅샷입니다. 이전 Git 이력, 내부 기술설명서와 그 생성 코드, 캐시, 비밀 설정, 실제 점포 데이터는 포함하지 않습니다. 계산 과정과 테스트는 유지하고 내부 문서 용도를 언급한 주석만 포트폴리오 표현으로 정리했습니다.
